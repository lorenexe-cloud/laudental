LAU DENTAL — VERSIÓN 3.0

Incluye:
- Logo oficial de Lau Dental.
- Fotografía real optimizada de la fachada.
- Dirección, teléfono, WhatsApp, horarios y mapa confirmados.
- Diseño adaptable a celular, tablet y computadora.
- Botones flotantes de WhatsApp y Agendar cita.
- Panel Decap CMS en /admin (requiere configurar una sola vez el autenticador OAuth indicado en admin/config.yml).
- No incluye chat inteligente.

ACTUALIZAR EL SITIO EN GITHUB
1. Descomprime este ZIP.
2. En el repositorio lorenexe-cloud/laudental elimina los archivos anteriores, excepto .git si usas GitHub Desktop.
3. Sube TODO el contenido de esta carpeta a la raíz del repositorio.
4. Confirma que index.html, css, js, img, content y admin estén en la raíz.
5. Haz Commit changes. Cloudflare publicará automáticamente.

IMPORTANTE
El sitio público funciona sin activar el panel. Para que /admin pueda iniciar sesión y guardar cambios, todavía hay que crear/configurar el autenticador OAuth de GitHub y reemplazar TU-AUTENTICADOR en admin/config.yml.
